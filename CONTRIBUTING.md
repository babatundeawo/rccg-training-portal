# Contributing

Corrections to study text, verses or test questions are welcome.

1. Open an issue using **Content correction**, or
2. Edit the file on GitHub (pencil icon), choose **Create a new branch and start a pull request**, and describe the change.

Study content lives in `assets/data/*.json`. Every pull request is built and checked automatically; a `site-preview` download is attached to the check so you can see the result before it is merged. Please do not add new content that is not from the RCCG manuals.
